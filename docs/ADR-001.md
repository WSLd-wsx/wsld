# ADR 001: single PE, process-lifetime GUI and outstanding deployment limits

Accepted: native Rust/MSVC, one console-subsystem PE under three names, embedded
Core and a sibling Tauri DLL using a new v2 C boundary. Historical Stage B and
Iris Xe evidence supports this constrained model, not installation acceptance.

Retain the console subsystem until measured terminal/script/pipe/exit-code,
Ctrl+C and Explorer/ShellExecute evidence supports a better same-PE solution.
Do not patch just the GUI copy's header. A console window/flash remains possible.
The reference screenshot observed conhost; no flicker-free claim is made.

Tauri's default Windows icon helper reads resource 32512 from the EXE. Provide
that minimal public Windows resource in the host, independently of private GUI
sources/framework code. Do not patch Tauri or build a second GUI executable.

Reject network/nonfixed/reparse paths for GUI loading. Directory ACL/write
admission, replacement races between inspection and loading and publisher signature
verification remain limitations. Path checks alone do not authenticate code.

The DLL stays resident even on errors. GUI return and task drainage do not prove
all framework threads/window classes can be unloaded. One loop per process;
subsequent GUI invocations require a new process. catch_unwind covers Rust unwind
only, not SEH, bad pointers, abort or arbitrary renderer failure.

No stable minimum Core/graphics pairing is invented to admit existing Drafts.
CachyOS future rolling ordering remains undefined; ordinary latest rejects it.
Rootfs unpacked_size measures filesystem logical content, not decoded tar length.
A decoder must not use that value as an exact tar byte limit.

## Migration execution checkpoint

The initial preflight failed because MSVC/SDK were absent. After explicit user
authorization they were installed; Rust/MSVC builds and the real product GUI
suite now pass. The installer requested restart (3010),
but no restart was performed and native checks passed in the current session.
Historical prototype PE files were not substituted. The public resource 32512
contract now has real product-window evidence. Observed conhost children confirm
that the console-subsystem UX limitation remains; Explorer flicker, ShellExecute
and Ctrl+C are still not accepted by the pipeline/redirection tests.

Current offline release resolution consumes an explicitly supplied JSON index
whose entries identify local, byte-verified asset directories. It is not a
GitHub catalog downloader and cannot authorize installation. Even a resolved
synthetic compatible manifest reports installation_admitted=false until the
paired native component admission is implemented. No network download, resume,
zstd decoding, WSL import, account initialization or desktop operation is hidden
behind the diagnostic tasks or the inventory endpoint.
