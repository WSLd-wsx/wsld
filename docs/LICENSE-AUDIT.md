## Integration boundary

`integration/graphics-lifetime/guest_retirement.rs` explicitly retains MIT.
The reference presenter, window adapter and bootstrap carry MIT identifiers.
The integration directory's MIT grant covers owned helpers and patch contributions;
it does not replace notices on upstream files copied by the preparation scripts.
Those scripts produce source trees and bundles from separately supplied inputs.
The dependency inventory for the public PE does not certify those outputs.

## Integrity follow-up

The first inventory check only required the Unicode and integration license files
to exist. It now verifies their hashes, as well as the embedded CLDR table, in both
the offline Python checker and the Windows build's existing notice check.

No source adapter, icon, fixture, reference repository or runtime component was
replaced as part of this follow-up.

Outstanding work remains any separate provenance review for other migrated
materials and the toolchain/external-component distribution
